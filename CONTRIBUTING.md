# Contributions

Inline is developed by its maintainers. We are not accepting external pull requests at this time, including documentation-only changes. Maintainers may submit internal pull requests.

Bug reports and feature feedback are welcome through the project's support channels. Do not post credentials, private chats or security vulnerabilities in public issues.

For maintainers, use the package-specific checks and preserve compatibility of published package identifiers. See [AGENTS.md](AGENTS.md) for repository layout and working rules.
