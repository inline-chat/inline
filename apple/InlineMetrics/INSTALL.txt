Inline Metrics for Mac
======================

Requires macOS 14 or later. Supports Apple Silicon and Intel Macs.

1. Drag Inline Metrics.app into your Applications folder.
2. Open Inline Metrics and sign in with your own Inline admin email,
   password and authenticator code. A normal chat account is not sufficient.
3. Right-click the desktop, choose Edit Widgets, search for Inline Metrics,
   and add the small, medium or large widget.
4. Enable Open at login in the app if you want automatic updates after restarting.

You can close the app window. Leave the chart icon running in the menu bar
so it can check for new data about every five minutes. Clicking the refresh
arrow opens the app and checks immediately. macOS controls widget redraw timing.

Red and green arrows compare today so far with the whole previous UTC day.
The admin session lasts up to three days; sign in again in the app when asked.

This package contains only the app and these instructions. It contains no
saved account, password, admin session or cached metrics. Each person signs in
separately; credentials stay in their Mac's Keychain.

Opening this development build
------------------------------
This is an internal, development-signed build, not an Apple-notarized release.
macOS may block the first launch. If you received this build directly from
someone you trust, try opening it once, then go to System Settings >
Privacy & Security > Open Anyway and confirm the app you intended to open.

Apple's instructions:
https://support.apple.com/102445

If Open Anyway is unavailable or your Mac is managed, ask your administrator
or build the app from the repository with your development signing team.

Source and build instructions: apple/InlineMetrics/README.md in the Inline repo.
