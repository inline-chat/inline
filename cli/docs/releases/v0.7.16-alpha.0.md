# Inline CLI 0.7.16-alpha.0

This alpha includes the recent CLI and local-agent bridge changes since 0.7.15.

- Improves command ergonomics, message selection, forwarding output, text-file
  input, and actionable error messages.
- Improves provider recovery and keeps model settings available when optional
  provider configuration reads time out.
- Keeps Codex input clean while preserving Inline identity links and native
  conversation context.
- Includes the expanded authorized chat catalog and current chat-history and
  resource-loading protocol.
- Installs the exact OpenClaw `0.0.71-alpha.1` and Hermes `0.0.22-alpha.0`
  packages for agent setup. OpenClaw adds opt-in quiet activity timelines;
  Hermes filters typed service notices before agent admission and retains
  ordinary typing.

This prerelease uses versioned download artifacts. The stable CLI manifest,
Homebrew cask, and npm `latest` tags remain on their current releases.
