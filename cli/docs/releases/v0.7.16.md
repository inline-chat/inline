# Inline CLI 0.7.16

Inline CLI 0.7.16 includes the CLI and local-agent bridge changes since 0.7.15.

- Improves command ergonomics, message selection, forwarding output, text-file
  input, and actionable error messages.
- Improves provider recovery and keeps model settings available when optional
  provider configuration reads time out.
- Keeps the macOS bot bridge responsive by using launchd’s Standard process
  policy, preventing background throttling during provider startup and replies.
- Keeps Codex input clean while preserving Inline identity links and native
  conversation context.
- Includes the expanded authorized chat catalog and current chat-history and
  resource-loading protocol.
- Installs the stable OpenClaw and Hermes packages for agent setup, requiring
  OpenClaw `0.0.71` and Hermes `0.0.22` or newer. OpenClaw adds opt-in quiet
  activity timelines. Hermes filters typed service notices before agent
  admission, preserves ordinary typing, and fixes private-chat participant
  defaults and clarification button layouts.

Available for Apple silicon macOS and Linux ARM64/x86-64 with GNU and musl
variants. macOS artifacts are signed and notarized.
