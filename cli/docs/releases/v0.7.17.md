# Inline CLI 0.7.17

Inline CLI 0.7.17 improves large file transfers and native downloads.

- Uploads documents and videos up to 500 MB through the native transfer protocol.
- Preserves upload identity and accepted bytes across reconnects, so recovery does
  not create duplicate files. New accepted bytes replenish the recovery budget.
- Bounds connection recovery, video metadata preparation and post-upload processing
  while allowing a healthy large upload to continue without a whole-file deadline.
- Adds `inline messages download --native` for a single document with verified
  512 KiB ranges and recovery on both V2 and V3. Server admission limits and storage
  timeouts retry with backoff; authorization and integrity errors remain terminal.
- Publishes CDN and native downloads only after completion, preserves existing
  destination files, and removes incomplete staging files. CDN downloads keep
  completed legacy files when their stored size differs and log the mismatch.

Native downloads remain an explicit `--native` option. Default and batch downloads
continue to use the CDN. Native downloads currently support one document at a time.

Available for Apple silicon macOS and Linux ARM64/x86-64 with GNU and musl
variants. macOS artifacts are signed and notarized.
