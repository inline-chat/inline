# Inline CLI 0.7.18

Inline CLI 0.7.18 makes the background agent bridge run unattended. It stops
restart loops and recovers on its own.

- A second bridge process for the same account now waits on standby and takes
  over when the first one exits. Previously it failed every 10 seconds with a
  misleading disk-space hint. Commands that hit the lock report
  `bridge_already_running`.
- The bridge stops retrying only when a restart cannot help: Inline explicitly
  revoked or expired the session or deactivated the account, the bridge has no
  Inline sign-in, its configuration was removed, or an agent's runtime is
  missing. These show as `needs_setup` in `inline bridge status`,
  `inline bridge doctor` and `inline doctor`, and the service manager no longer
  restarts the bridge for them. A request denied with a plain 401 or 403 never
  stops the bridge on its own: the bridge first confirms the sign-in with one
  authenticated check and keeps running if it is still valid.
- Server rate limits wait the time the server asks for, up to an hour. Other
  failures (network, timeouts, server errors, unknown errors) keep retrying
  with jittered exponential backoff. Agents back off for at most 5 minutes and
  the service for at most 3 minutes. The backoff persists across restarts and
  resets after 60 seconds of healthy running.
- Self-healing: after `inline login`, a bridge whose sign-in expired gets the new
  sign-in and restarts. An agent whose runtime was missing resumes within about
  2 minutes of the runtime being installed. Edits to the operator allowlist in
  `~/.inline/config.toml` apply without a restart. `inline update` restarts the
  bridge on the new version even while an agent still needs setup.
- Error reports are limited to one per failure type per day for each
  installation.

Bridges that are stuck in a restart loop recover after updating to this version.
If `inline bridge status` then shows `needs_setup` because the Inline sign-in
expired, run `inline login` once.

Available for Apple silicon macOS and Linux ARM64/x86-64 with GNU and musl
variants. macOS artifacts are signed and notarized.
