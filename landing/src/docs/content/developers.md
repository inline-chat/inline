## APIs

- [Bot API](/docs/bot-api): HTTP, bot token, polling or webhooks.
- [Realtime API](/docs/realtime-api): WebSocket RPCs, updates, and live state.
- [MCP](/docs/mcp): hosted tools with user OAuth consent.
- [CLI](/docs/cli): signed-in terminal and script access.

## SDKs

- `@inline-chat/bot-client`: TypeScript Bot API client.
- `@inline-chat/realtime-sdk`: TypeScript Realtime client.
- `inline-sdk`: low-level Rust API and Realtime RPCs.
- `inline-client`: stateful Rust cache and sync client. (experimental)
