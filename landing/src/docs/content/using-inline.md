Inline is available on [macOS and iOS](/docs/downloads). You can use it with other people without installing the CLI or connecting an agent.

## Sign In

Open the app and choose a sign-in method. If you choose email or phone, enter the confirmation code sent to that address or number. Complete any profile or invite steps the app requests. Use the same account when signing in on another device.

If setup asks for an invite you do not have, [contact us](/docs/troubleshooting#report-a-problem). Do not share sign-in codes in a chat or support report.

## Choose Home or a Space

| Context | Use it for |
| --- | --- |
| Home | Direct messages and threads outside a team space. You do not need to belong to a space. |
| A space | Conversations within a team or another shared context. |

Select the context before starting a conversation. A space can contain public and private threads, so check the conversation's visibility as well as its destination.

## Start a Conversation

Start a direct message to talk to one person, or create a thread for a topic. In a space, the creation flow offers **Public** and **Private**; private threads let you select people to invite.

Give the thread a title that makes it easy to find again, then send the first message. For example, a “Website feedback” thread can hold screenshots, questions, and decisions about one page.

Before sharing sensitive material, check [who can read the thread](/docs/chats-and-threads#who-can-read-a-thread). A reply thread inherits access from its parent; it is not a private aside just because it opens separately.

## Keep a Discussion Focused

Use a reply thread when a particular message needs its own discussion. Open the reply count beneath the message to continue that conversation. You can return to the parent without mixing every reply into the main discussion.

Use another top-level thread when the topic needs a different audience. See [Chats and Threads](/docs/chats-and-threads) for access, following, and notification behavior.

## Find a Conversation Again

On iOS, **Open** is your current working set and **All Chats** shows visible conversations, including chats you have closed. A reply thread may stay hidden from that list until opened from its parent. Use **Search** to find a conversation. On macOS, the sidebar is your working set; use **Command-K** to find and reopen chats.

**Close** removes a conversation from your working set. It does not delete its messages or close it for everyone else. **Follow** and **Notifications** control different aspects of attention; choosing per-thread **All** notifications also enables Follow. Closing a chat is not a way to revoke access or guarantee silence.

## Add an Agent When You Need One

To talk to an agent from Inline, [set up a bot integration](/docs/agents). To let an agent you already use read approved Inline context, [connect MCP](/docs/mcp) or [install the plugin or skill](/docs/add-inline).
