Service worker lab

Only does anything in a production build with the service worker plugin, served by vite preview: from web/, bunx vite build -c tooling/vite.labs.config.ts --outDir <dir> then bunx vite preview -c tooling/vite.labs.config.ts --outDir <dir> and open /lab-sw.html. In vite dev registration is disabled and any leftover worker is removed. Unregister here before going back to vite dev on the same port.
